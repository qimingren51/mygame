# 提灯夜行 · 质感设计

> 状态：v0.1（2026-10-13）。质感会话负责本文和下面列出的实现。
> 范围：镜头、时间、粒子、光与后期、高光时刻的演出、声音——让每一下打击、每一次升阶、每一夜的收尾都有分量。
> 对应 `docs/GAMEPLAY.md` 第 14 节“爽点与反馈”的清单；技术架构见 `docs/DESIGN.md` 第 9–11 节。

## 1. 原则

1. **分量来自对比。** 平时克制，大事件才放开：小妖死只溅一点墨，精英爆墨，夜主倒下全场静半拍、慢镜、天明。
2. **水墨里的光。** 暗处只有灯、火、妖眼、魂火和一点月色的薄雾在亮；墨色的东西（化墨、灰、墨滴）画在暗层之下，只在灯照到的地方看得见。
3. **看得清比热闹重要。** 特效有预算：一帧里命中、击杀放的粒子有上限，满地魂火时光斑自动减弱，反应名不占提示栏。敌方攻击预警永远最显眼（`GAMEPLAY.md` 第 4.5 节）。
4. **全在画面层，不碰模拟。** 震屏、缩放、粒子、暗角都只在画面层；顿帧和慢镜只调 `Time<Virtual>` 的速度，模拟照样一步一步走，回放和确定性不受影响。
5. **都能关。** 设置里有震屏强度（0–100%，同时管手柄震动）、顿帧、辉光、特效（完整 / 精简）四项。

## 2. 镜头与时间（`crates/view/src/camera.rs`）

- **跟随**：镜头对准主角插值后的位置，移动时朝前看 16 个世界单位，停下慢慢回中。
- **震屏**：创伤模型。事件往“创伤”里加量（封顶 1，大事件同时发生也不会晕），每秒衰减 1.5；位移 = 14 × 创伤² × 平滑噪声，另带不到 1.3° 的侧倾。用现实时间，顿帧时也在抖。
- **方向冲击**：落印往下一顿、九尾扫顺着扫的方向一推、闪避往反方向一拽，再用临界阻尼弹簧弹回（解析解，帧长再大也不发散）。
- **缩放冲击**：只往里推（最多 12%），不会露出视野外刚刷出的妖物（模拟的视野按 21:9 算，`DESIGN.md` 第 6.1 节）。光照相机和暗层跟着同步缩放、侧倾。
- **顿帧**：`Time<Virtual>` 速度设为 0，持续几十毫秒；同类顿帧至少隔 0.18 秒。
- **慢镜**：速度降到 0.2–0.3，最后四成时间平滑回到 1。
- **手柄震动**（`crates/platform/src/rumble.rs`）：同一张表里挑出受伤、精英倒下、大暴击、闪避、进化落印、震地、燃灯、九尾扫、回光、夜主登场 / 换阶段 / 倒下、倒下几项；一帧只取最强的一次，强度跟着设置里的“震屏”。

## 3. 粒子（`crates/view/src/particles.rs`）

- 固定容量 1800 的 CPU 粒子池，不创建实体：普通混合的进精灵池（受光照），叠加混合的进发光池（画在暗层之上）。粒子用虚拟时间，顿帧时一起停。
- 贴图在启动时用代码画好，作为图集的一页（`AtlasDb::add_page`）：软点、火线、烟、灰、余烬、墨滴、雾、笔触。不依赖美术管线。
- 一帧最多为 28 次命中、32 只妖物的死亡放粒子，多出来的按比例降级（伤害数字和墨点照常）。

| 时刻 | 粒子 |
| --- | --- |
| 命中 | 2–3 道火线，颜色按这一击的五行，朝远离主角的方向溅 |

| 九尾扫 | 一道红色的大笔触 |

| 走路 | 每走 26 个单位脚下起一点尘 |

## 4. 光与氛围（`crates/view/src/atmos.rs`、`lib.rs`）

- **辉光**：主镜头开 HDR 和 Bloom（叠加模式，阈值 1.0，强度 0.16）；燃灯、夜主倒下、回光、进化、灯阵完整、反应初见时强度猛地拉高（最多 +0.45）再回落。画在主画面上的自发光亮度乘 1.5（`EMIT_HDR`），叠起来超过 1 的部分才晕开；纸面和墨色不受影响。设置里可关。
- **魂火的光**：场上魂火越多每颗越暗（60 颗以上按比例减到三成），后期不再糊成一片光斑。
- **暗角**：Bevy 自带的 `Vignette`，平时很淡；受伤时一跳并泛红，配一点色差，挨打的那一边收得更近（暗角中心往反方向挪，最多 0.16）；生命低于三成时随心跳收紧、泛红，灯笼的光圈也忽大忽小（灯焰摇曳）。
  - 挨打的方向：`PlayerHurt.from`，伤害从哪儿来——碰撞、冲锋是妖物的位置，弹幕是弹的位置，九尾扫是扇形的顶点，狐火雨是落点。
- **萤火**：40 点暖黄和淡绿的光绕着镜头飘，忽明忽暗，画在暗层之上。
- **夜雾**：9 片冷蓝的薄雾慢慢横移，叠加在暗层之上，暗处泛起一层月色，亮处几乎看不出。
- **青丘迷雾**（`mist.rs`）：美术的 `vfx/mist_0`（大团）、`mist_1`（碎团）是无缝平铺的贴图。图集里不能重复采样，一格格铺会露出接缝，所以图集加载好后把这两帧拷成单独的重复采样贴图，每层一个盖住镜头的大四边形，UV 跟世界坐标走、各自漂移（7、−2 和 −12、3.5 单位 / 秒），染 `#DDD9CF`，叠在暗层之上、普通混合。不透明度 0.05、0.035，比美术建议的 0.2、0.15 低很多：HDR 镜头在线性空间里混合，亮雾盖在暗处要亮得多。天明时淡一半，成了晨雾。夜签“浓雾”（灯光范围 −30%）的夜里不透明度 × 2.6、漂移 × 0.6，让减掉的灯光看得见。现在只有青丘一个地区，所以每局都有一层淡的；以后有别的地区时只在青丘画（美术原本是给 EA 险地狐冢的整夜迷雾准备的，到时候用浓雾那一档）。
- **夜主登场**：光照图的底色 0.4 秒压暗 45%，停一会儿，最后 1.5 秒回来。换阶段时同样压一下，短一些、浅一些（1.8 秒，压暗 30%）。
- **无尽夜**：夜主倒下也不天明（`BossDefeated { dawn: false }`），只有辉光一闪。夜深一层（`NightDeeper`，10 分钟以后每 5 分钟，和妖潮同时）时夜色先猛地压一下，再在 3 秒里停到更暗的一层（每层暗 6%，最多四层），晚半拍响一声低锣，一个音从 D4 沉到 D3——“梦太深，光透不上来……夜就一层层深下去”（`LORE.md` 第 8 节）。
- **天明**：夜主倒下 0.8 秒后，光照图的底色用 3 秒从夜色经过晨光（暖桃色）变成白天；剩下的妖物淡去、化成墨烟；萤火和夜雾散去（`GAMEPLAY.md` 第 4.2 节）。

## 6. 声音（`crates/audio/`）

- **空间**：一条混响发送轨（大殿般的长余音），音效送 −11 dB，音乐送 −9 dB。古筝和编钟有了空间感。
- **压缩**：音效轨挂压缩器（阈值 −10 dB，3:1），几百次命中叠在一起也不会炸。
- **声像**：命中、击杀、纸鹤、落印、爆炸、反应按相对主角的左右做声像（最多 ±0.75），按远近衰减（最多 −9 dB）；全屏的钟鸣、太极不分左右。
- **新音效**（全部代码合成，`cargo test -p lantern_audio` 检查不削波）：
  - 暴击：清脆的金属声（编钟泛音 + 高频噪声）；
  - 盖章：太鼓低音 + 木鱼的闷响（共鸣跨阶、反应初见）；
  - 连斩：三声鼓点接钟；
  - 精英倒下：一声沉的；
  - 濒死心跳：生命低于三成时“咚、咚”，越低越急、越响；
  - 夜主换阶段：太鼓一击、低锣，一声狐啸（三角波从 520 Hz 挑到 1100 Hz，再拖着落到 380 Hz，底下垫低八度的正弦和一道扫下来的带通噪声）；
  - 夜主倒下：全场（音效和音乐）静 0.55 秒，接一声低锣和太鼓；1.6 秒后编钟三响、晨鸟。
  - 竹丛打碎：一声脆的“咔嚓”（高频噪声 + 几声木响），后面跟几下竹片的噼啪；每 0.07 秒最多一声，音高随机，按位置做声像；
  - 竹丛烧平：呼地一下着起来（低通噪声从 300 Hz 扫到 2400 Hz），噼里啪啦，跟在夜主登场的警报后面 0.3 秒。
- **界面上的声音**（界面发 `UiCue`，音频照着播）：
  - 开场卷轴展开：一声低的拨弦，纸沙沙地推开（一串短的带通噪声颗粒，越推越轻），推到头时轴头一磕；
  - 旁白每浮出一行：很轻的一声高音，一行比一行高（五声音阶往上走）；
  - 灯驿点亮一盏心灯：呼地着起来，一个暖的和音，几下噼啪；几盏依次点亮时一盏一声；
  - 灯驿远山晨光铺开：一串往上走的拨弦，末尾几声鸟叫。

## 7. 预算与开关

| 项目 | 预算 |
| --- | --- |
| 粒子 | 同时最多 1800；每帧命中 28 次、击杀 32 只放粒子 |
| 萤火、夜雾、迷雾 | 40 + 9 个绘制；迷雾两个全屏四边形 |
| 辉光 | Bevy Bloom，最大 mip 512；设置可关 |
| 震屏 | 创伤封顶 1；设置里 0–100% |
| 顿帧 | 同类至少隔 0.18 秒；设置可关（慢镜一起关） |
| 特效：精简 | 成团的粒子减半（至少留一个），上限 900；不画走路扬尘、灯火飘的火星、萤火、夜雾、迷雾的碎团那层和色散。截图对比：同一刻粒子约 500 → 280，发光 800 → 650，画面差别不大。辉光另有开关 |

F3 性能面板显示画面层每帧的耗时（只算画面系统，不含渲染）和精灵、发光、粒子的数量（`lantern_view::ViewStats`）。云端调试版、约 1000 只妖物、800 个粒子时画面层约 2.2–2.5 ms。

设置文件 `settings.ron` 新增 `shake`、`hitstop`、`bloom`、`lite_fx` 四项（带默认值，旧文件照常读）。画面层不依赖平台层：设置由界面层同步到画面层的 `Feel` 资源。

## 8. 怎么看效果

云端没有显卡，用软件 Vulkan（lavapipe）加虚拟显示器截图，帧率很低，只能看画面、看不了手感；手感以本机试玩为准。

```bash
# 机器人无敌打一局，存成回放，并打印关键时刻（进化、反应初见、夜主登场、伏诛、退去……）
cargo run --release -p lantern-tools -- kite --runs 1 --seed 3 --god --record bot.ron
# 在游戏里从第 705 秒开始看（读 1 MB 的回放在调试版里要半分钟）
cargo run -- --replay bot.ron --from 705
```
