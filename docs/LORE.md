## 0. 一页总览

**一句话**：烛龙守了一千年的约，终于睡着了，它的梦就是长夜。最后一个守灯人提着从它那里借来的光，从五方夜主手里取回五缕烛火，去章尾山叫醒它，再把借来的光还给它。

**题眼**：《六祖坛经》“一灯能除千年暗。”

**四条世界规则**：所有名字和玩法都从这四条推出来，新内容不能违背。

| 规则 | 内容 | 推出来的玩法 |
| --- | --- | --- |
| 光是龙的目光 | 白天是烛龙睁眼时的目光。守灯人灯里的长明火、夜主守着的烛火，都是烛龙的目光 | 照见（被龙看见的妖受伤加重）；燃灯；击败夜主那一刻天明 |
| 魂被妖困住 | 长夜里的妖物都靠吞魂撑着。打散妖物，魂就飞向灯 | 魂火是经验；灯随魂变亮；天明时魂被送走，所以每一夜从一级开始 |
| 名字有力量 | 知道妖的名字，才制得住它；妖知道你的名字，就能叫走你的魂。所以长夜里人人不报真名 | 说书人讲过的妖受伤加重；判官圈你的名字；主角没有名字 |
| 长夜是一场梦 | 长夜是烛龙的梦，会一遍遍重做 | 同一个地区可以一夜一夜地重来；夜主倒下后，下一夜又站起来 |

**道具名字要有关联**：每个名字至少连着另一样东西：来源的妖物或地区、同一条法器链、同一个传说、同一个关键字。见第 9 节。

## 1. 世界规则

### 1.1 光

- 世上的白天，是烛龙睁眼时的目光；黑夜，是它闭上了眼。《山海经·大荒北经》说烛龙“其瞑乃晦，其视乃明，不食不寝不息”；《海外北经》叫它烛阴，“视为昼，瞑为夜”。睁一只眼，天只有鱼肚白；两只眼都睁开，才是大白天。
- 人们说的“太阳升起来”，就是烛龙睁开了眼。【新】本作不用金乌、十日、羲和这一套，免得白天有两个来源。
- **长明火**：一千年前，第一代守灯人上章尾山，向烛龙借了一缕目光，点在灯里，这就是长明火。长明火只有一朵，由当代的守灯人提着，一代代传下来。它不会灭，只会暗。提着长明火的那盏灯，叫长明灯。
  - 其他守灯人的灯，是从长明火分出去的火（《维摩诘经》的“无尽灯”：一灯燃百千灯，明终不尽）。分出去的火随人灭，长明火不会。【新】
- **烛火**：烛龙自己留着的目光，分青、赤、黄、白、玄五色。长夜开始那一夜，五缕烛火从它闭上的眼里散落五方，被五方各自最强的妖与神接住，它们就成了夜主。
- **烛火被守着就照不出去**【新】：九尾把青火挂在狐村，毕方攥在爪里，土伯举在手里，刑天嵌在胸前，相柳吞进肚里。被守着的烛火只照亮守它的东西身边，照不亮天。守火的夜主倒下、松了手，光才放出去，那一片天就亮了，这就是每一夜的“天明”。长明火是烛龙借出来的，本来就是放开的，所以照得出去。
- 所以：
  - 照见圈里的妖物，等于被龙看见了，受伤加重。
  - 燃灯是把灯罩全打开，让龙的目光一下照满全场，妖物成片化灰。
  - 土伯举着黄火也造不出天亮，毕方攥着赤火也当不了太阳。
- 择灯是给长明火换一副灯身。灯身不同，光色不同，火是同一朵火（`GAMEPLAY.md` 11.4）。

### 1.2 魂

- 长夜里死去的人和兽，没人引魂，魂被黑暗一层层裹住，就成了鬼。草木、山石、器物吸了魂，成了精；鸟兽修成了妖，也靠吞魂撑着；阴差身上带着拘来的魂。妖物的眼睛在暗处发光，是因为肚子里有魂。【新】
- 打散妖物，墨色的壳炸开（击杀时的墨点），魂露出来，循着灯飞去，这就是魂火。《淮南子·氾论训》：“久血为燐。”魂火就是燐火。
- 灯收的魂越多越亮（升级时照见圈扩开）。天明时，守灯人把这一夜收的魂送去往生，所以每一夜都从头开始。
- 守灯人的本分是引魂。中元节放河灯，是给水里的魂引路，所以引魂的心法属水。
- **倒下以后为什么还能再来**【新】：守灯人倒下时，灯身破了，长明火暗成一点火星，带着守灯人回灯驿。回去的路要有心灯在那头照着（心灯见 1.5 节）。这一夜收的魂散回夜里（等级没了）；人回来了，钱袋也还在（`GAMEPLAY.md` 11.1：倒下也带走全部铜钱）。
- **前几任守灯人为什么没回来**：长夜以前，长明火是守灯人老了才传给下一个人。长夜里，灯驿一座座被妖潮吞没；灯驿一黑，心灯就灭了，那里的守灯人倒下以后，回去的路没有光，就再也没回来，长明火只好自己去找下一个守灯人。提分火的守灯人，火随人灭。最后，长明火到了最后一座灯驿，到了你手里。这座灯驿再黑下去，就谁也回不来了。

### 1.3 名

- 白泽向黄帝说出天下一万一千五百二十种鬼神精怪的名字和样子，黄帝叫人画成《白泽图》。说书人手里有一本《白泽图》的残卷，就是游戏里的百妖谱，所以条目不全，要一条条去补。【新】
- 知道名字，是制得住它的前提，不是一叫就赢；名字要当面叫出来才管用。百妖谱里记下的妖，守灯人自己叫得出名字，对它伤害 +5%；说书人当面讲得全，那一夜 +25%（`GAMEPLAY.md` 2.5）。
- 反过来，夜里妖物喊你的名字，你一答应，魂就被叫走（民间说夜里有人叫名字，不要回头）。所以长夜里人人不报真名：
  - 灯驿的人都按行当称呼：老灯匠、说书人、灯童、货郎。
  - 守灯人接过长明火时，把写着名字的纸压在灯座底下，由长明火护着。
- 判官的生死簿上有你的名字，可名字压在灯座下、有长明火护着，他叫不走你的魂，只能把你圈住（圈里受伤加倍）。
- 毕方“其鸣自叫”，一直喊自己的名字。它不怕被叫名字，它就是想被天下记住，像凤凰那样。
- 人叫主角“守灯人”（他做的事），妖叫他“提灯人”（它们看见的样子）。界面和旁白一律用“守灯人”，妖物的台词用“提灯人”（已定）。游戏名“提灯夜行”也是这个叫法。
- 真结局里灯灭了，灯童掀开灯座，第一次念出你的名字。

### 1.4 夜

- 长夜是烛龙的梦。梦会重做，同一片地方一夜一夜地黑下来，夜主倒下了下一夜又站起来，所以每个地区可以反复去。
- **更**：同一个地方被梦重做得越多，夜就越深，叫作几更。五更是天亮前最黑的时候（难度“更”）。无尽夜里，梦重做得一次比一次快，夜也就一层层往下沉（第 8 节）。
- **日子**：长夜里没有天亮，灯驿靠漏刻和更鼓计时，说是已经三年。
- **鬼门**：每年七月初一打开，中元最盛，月底关上（`GAMEPLAY.md` 2.2）。可鬼门只认烛龙睁眼的天亮；夜主倒下时那一片天明，只亮一处、只亮一时，不算数。长夜里烛龙没再睁过眼，七月就永远过不完，鬼门也就关不上。三年里门被挤裂了，幽都里到处是门缝；人间各处冒出来的妖潮裂隙，也是它的裂缝。【新】
- 鬼门怕光：幽都里点亮门旁的灯，光是放开的，照得到门上，门缝就合上了。
- **取回的烛火**【新】：灯阵完整时，烛火迸出来被阵兜住，带回灯驿，供在灯台上，真火只取一次。梦重做时，夜主手里守着的是烛火在梦里的影子，照得出一时的天明，灯阵却兜不住。
- **妖物从哪来**：有的从鬼门出来（鬼、阴差），有的是本地生出来的（吸了魂的精、修成的妖）。所以青丘、北冥的妖物不必都从幽都来。

### 1.5 心灯

- 心灯是灯驿里的一棵灯树。百姓用灯油一盏盏点亮，为守灯人祈福；每点亮一个节点，灯驿的画里就多亮一盏灯（`GAMEPLAY.md` 11.3）。
- 树上有一盏是百姓专为你点的。它照在你身上，就是你的心灯：倒下时是它把你引回来；“无灯”时照见圈那 80 的光，也是它。长明火要还给烛龙，这一盏不用还。
- “灯可以灭，心灯不灭”说的就是它。

## 5. 主线为什么这么走

- **依相生的顺序走**（木生火，火生土，土生金，金生水）：母寻子。夜主倒下时烛火迸出的那道光，偏向它所“生”的那一系的方向（生我者为母，我生者为子），照出了下一程的路。所以通关一个地区就能去下一个，哪怕没拿到烛火。【新】
- 北冥之后，五方都走过一遍，五道光在天上会合，一起指向西北的章尾山。
- **灯阵**：五盏石灯笼是历代守灯人留下的阵。阵完整，烛火迸出来时被阵兜住，能带回灯驿；阵不完整，光亮一下就散回夜里，下一夜又回到夜主手里。这就是“灯阵完整才拿得到烛火”的原因。
- 五方都通关后就能去章尾山，不要求拿齐烛火；但只有五缕都在，烛龙才会开口（真结局）。
- **险地**是每个地区的深处，夜最浓。本地区通关二更，守灯人才摸清进去的路。

## 6. 六个地区

每个地区写清楚：出处、为什么属这一系、续写了哪段没讲完的神话、夜主为什么守着烛火、本地妖物和险地、开场卷轴（第一次进入时的旁白，约 60 字）。

### 6.1 青丘（木·东）

- **出处**：《山海经·大荒东经》“有青丘之国，有狐，九尾”；《南山经》青丘之山的九尾狐“其音如婴儿，能食人，食者不蛊”。青丘在东，东方属木。
- **续写**：九尾在古书里有两面：会吃人，也是涂山的祥瑞（《吴越春秋》里禹在涂山遇白色九尾狐）。长夜里，它是狐村所有小狐狸的母亲。
- **夜主的理由**：九尾接住了青火，挂在狐村的屋檐下，给怕黑的小狐照亮。你拿走它，狐村就又黑了。
- **本地妖物**：狐火、竹魅、讨封狐；精英赤面狐、石将；小头目青面鬼。
- **险地·狐冢**：狐狸的坟丘。
  - 鬼狐：死去的狐狸的魂。被打中时分出的那个叫幻身，和九尾的幻身同名（`GAMEPLAY.md` 8.5 写作“幻影”）。
  - 狐嫁女：民间说夜里撞见狐狸娶亲，冲撞了送亲的队伍要倒霉。《聊斋志异·狐嫁女》里的殷天官没冲撞，反倒做了上宾。
  - 整夜的雾叫迷雾（不叫“浓雾”，免得和夜签浓雾同名）。
- **教玩家的事**：看照见圈。狐的幻术进了照见圈就散，九尾的幻身没有影子。
- **狐火雨**：三更起九尾多的一招，每 6 秒在你身边落下 5 团狐火（`GAMEPLAY.md` 9.4）。夜越深，狐村越护得紧，狐火也下得像雨。
- **击败九尾后**：狐村的孩子一直收着一盏孔明灯，是很多年前一位守灯人留在狐村的。九尾倒下后，孩子们把它还给了你（“击败九尾解锁孔明灯”的由来）。【新】
- **卷轴**：青丘在东，竹海万顷，狐族世代住在这里。长夜以后，狐村的屋檐下挂起一团青火，那是九尾接住的烛火。竹林里游着狐火，像灯，又不是灯。
- **卷轴（天明）**【新】：第一次在青丘迎来天明以后，再出发时展开一次。三句一句一行，和长夜版逐句对着：竹海（颜色回到画里）、狐村（青火换成孩子还你的孔明灯）、狐火（像灯又不是灯，对“真的灯”）。“亮过一回”交代天明只是一时，梦还会重做这里的夜（1.4 节）。
  > 天亮过一回，青丘的竹海又青了。
  > 狐村的孩子还回一盏孔明灯，是从前的守灯人留下的。
  > 狐火还在竹林里游。可这一盏，是真的灯。

### 6.2 丹穴（火·南）

- **出处**：《南山经》丹穴之山，“有鸟焉……名曰凤皇……见则天下安宁”。毕方见《西山经》“其鸣自叫也，见则其邑有讹火”和《海外南经》“其为鸟人面一脚”。
- **续写**：凤凰只在天下安宁时出现。长夜里天下不宁，凤凰再没来过丹穴，毕方占了它的山。《淮南子·氾论训》说“木生毕方”（高诱注：毕方是木之精）：毕方生于木，却带来火，正是木生火，所以青丘之后是丹穴。
- **夜主的理由**：毕方接住赤火，攥在爪里，想自己当太阳，把夜烧穿。林子烧光了，夜还在。
- **击败毕方后**：赤火回来，天下安宁了一点，凤凰的影子在天明时掠过（建议的收尾画面）。合璧“百鸟朝凤”由此而来。
- **本地妖物**：
  - 火雀：毕方带的鸟群。南方是朱雀的方位。
  - 残灯：被讹火占了的古灯（古灯见 9.8 节）【新】。说明里的火统一叫讹火。
  - 火鼠：《神异经》说南方火山的火里有鼠，毛能织成火浣布。老鼠本来就会打洞，从脚下冒出来；和火雀、火精成一家。
  - 精英火精、赤面狐（火系）。小头目祸斗：《海外南经》厌火国“兽身黑色，生火出其口中”；明代《赤雅》说祸斗像狗、喷火作殃、不祥。吃火是后世的说法。
- **险地·令丘**：《南山经》里丹穴山往东一路数过去，有令丘之山，“无草木，多火”，和丹穴同在一组山里。那里还有一种鸟叫颙，人面四目，也喊自己的名字，“见则天下大旱”，可以留作以后的妖物。
- **卷轴**：丹穴山是凤凰的家。凤凰只在太平年月出现，长夜里，它再没来过。毕方接住了赤火，一只脚立在焦林里，一声声喊着自己的名字。

### 6.3 幽都（土·中·地下）

- **出处**：《楚辞·招魂》“君无下此幽都些。土伯九约，其角觺觺些……参目虎首，其身若牛些”；王逸注“幽都，地下后土所治也”。地下属土，居中。
- **鬼门**：《论衡》引《山海经》：沧海里有度朔山，山上大桃树枝间的东北方叫鬼门，万鬼由此出入；神荼、郁垒守门，用苇索捆住恶鬼喂虎。后来人们在门上画神荼、郁垒，挂桃木，这就是门神和桃符。【新】鬼门一头开在人间，一头通到幽都。
- **续写**：长夜那年七月过不完，百鬼冲散了神荼、郁垒，人间门上的门神画像一夜之间褪成了白纸。只剩土伯守门。
- **夜主的理由**：土伯接住黄火，举在手里，想造一个假天亮，把门哄上。可被他举着的光照不出去，门合上一半，又被冲开。他从有鬼门起就守着这扇门，这三年一刻也没合过眼。烛龙睁不开眼，土伯闭不上眼。
- **土伯的东西**：他拿墨线捆从门缝里钻出来的僵尸，拿宝塔压住门缝。他倒下后，这两样归了你（“击败土伯解锁墨斗和镇妖塔”的由来）。【新】
- **阴司**：判官、牛头马面、鬼卒是后来盖在幽都上面的衙门，长夜里乱了套，见了活人就拘魂。
- **本地妖物**：
  - 僵尸、鬼卒。
  - 纸人：人们烧给死者的纸扎。火一点就“送到了”，所以被点着后跑得更快。
  - 精英牛头、马面。小头目判官：生死簿上有你的名字，你自己都快忘了的那个。他用笔圈住你，圈里受伤加倍。
- **险地·十八层**：阴司衙门底下的十八层地狱，刀山、油锅、寒冰、黑狱都是民间说的地狱名。
- **卷轴**：地下有城，名曰幽都。鬼门七月初一开，月底就关。可长夜里七月过不完，门再也关不上。土伯举着一团黄火守在门口，三只眼睛一只也没合过。

### 6.4 常羊（金·西·古战场）

- **出处**：《山海经·海外西经》“形天与帝至此争神，帝断其首，葬之常羊之山。乃以乳为目，以脐为口，操干戚以舞”；陶渊明《读山海经》“刑天舞干戚，猛志固常在”。
- **续写**：那一仗打完几千年了，刑天还在打。后来历代的败兵也埋在这里，陪葬的俑一层压一层。长夜里，俑替死人站了起来。
- **夜主的理由**：刑天没有头，也就没有眼睛。他接住白火，嵌在胸前当眼（以乳为目），以为长夜是帝又打过来了。
- **首冢**：他的头埋在常羊山下。三阶段点亮冢旁的灯就能镇住他（`GAMEPLAY.md` 9.4）：光照到头，身子才肯停下。
- **击败刑天后**：他终于看清不是帝，只是天黑了。这一仗打完了。
- **本地妖物**：
  - 陪葬的偶像：兵俑、弩俑（秦俑里本来就有跪射的弩手）、小头目骑俑；精英铜人（《史记》秦始皇收天下兵器“销以为钟鐻，金人十二”，属金）、石将（陵墓神道两旁的石人，民间叫翁仲）。
  - 真正的死人：白骨。战场上的骨头，火和土能把它打散。
- **险地·兵冢**：埋兵的大坟，兵阵还在一排排往前推。常羊的三个“冢”（兵冢、首冢、合璧万剑冢）同字同义，都是埋东西的坟。
- **卷轴**：常羊山下埋着刑天的头。他的身子还在打那一仗，胸前燃着一团白火，当作眼睛。山下陪葬的俑，一排一排站了起来。

### 6.5 北冥（水·北·冰海）

- **出处**：《庄子·逍遥游》“北冥有鱼，其名为鲲……化而为鸟，其名为鹏……是鸟也，海运则将徙于南冥……去以六月息者也”。相柳见《海外北经》：“共工之臣曰相柳氏，九首，以食于九山。相柳之所抵，厥为泽溪。禹杀相柳……禹厥之，三仞三沮。”
- **续写**：
  - 鲲化成鹏，要等海动起来（海运）才往南冥飞，乘的是六月的大风。长夜里海冻住了，鲲困在冰下，化不了，飞不走。
  - 相柳早被禹杀了。鬼门一开，死了的凶神也回来了。走过的地方又成了毒泽；要用土填三次才填得平，就是“三仞三沮”。
- **夜主的理由**：相柳只是饿，它把玄火吞了。它是五个夜主里唯一纯粹的恶，不给它洗白。
- **击败相柳后**：冰面裂开，海又动了，鲲化而为鹏，乘风往南冥飞去（建议的收尾画面）。所以小头目鲲打不死：生命打空时沉回冰下，照样掉宝箱（`GAMEPLAY.md` 8.4，已采纳）。
- **本地妖物**：
  - 水鬼、冰魄（海冰吸了魂成的精，打散后留下一片冰面）、夜叉（龙宫的巡海夜叉，《封神演义》里被哪吒用乾坤圈打死的就是它的同类）。
  - 精英冰蚕：《拾遗记》员峤山“有冰蚕长七寸，黑色，有角有鳞，以霜雪覆之，然后作茧”，所以会吐冰丝。精英玄龟：北方玄武。
  - 小头目鲲。
- **险地·冰渊**：北冥最深的冰海，浮冰下面就是渊。
- **卷轴**：北冥有鱼，其名为鲲，化而为鸟，其名为鹏。海冻住了，鲲困在冰下，化不了，也飞不走。冰上，九个头在吃夜。

### 6.6 章尾山（终章）

- **出处**：《山海经·大荒北经》“西北海之外，赤水之北，有章尾山。有神，人面蛇身而赤……是谓烛龙”。终章的“赤水妖潮”就出自这里。
- **本地妖物**：
  - 烛阴卫【新】：烛龙从灯里看了历代守灯人一千年，梦里替它守山的影子，就长成了他们的样子。你在这里和前辈的影子交手。
  - 各地妖物的影：梦里的影子，墨色更浓，更快。
  - 五方夜主的残影：梦把它见过的夜主又演一遍。
- **灯阵**：终章吞光时要点亮的 5 盏灯就是章尾山的灯阵（不叫“祭坛的 5 盏灯”，免得和奇遇血祭坛混）。
- **夜主·长夜**：就是烛龙的梦。三个阶段：夜幕（梦藏进黑暗）、镜像（龙从你灯里看过你出手，梦里照着复制你最强的三件法器）、烛龙睁眼（守住灯阵，等它醒）。真结局在这之后多一段“九首吞日”（第 8 节）。
- **卷轴**：西北海之外，赤水之北，有章尾山。烛龙睡在山上，已经三年。它的梦，就是这三年的夜。你提着灯，来叫醒它。

## 7. 夜主台词

每个夜主四句：登场、两次换阶段、倒下（`GAMEPLAY.md` 2.5）。换阶段那句尽量顺带提示怎么打。

| 夜主 | 登场 | 第二阶段 | 第三阶段 | 倒下 |
| --- | --- | --- | --- | --- |
| 九尾 | 提灯的，这团火是孩子们的。 | 灯下有影子的，才是我。 | 孩子们，闭上眼。 | 去吧，提灯人。天亮了，记得狐也怕黑。 |
| 毕方 | 毕方！毕方！ | 烧！烧到天亮！ | 凤凰做得到的，我也做得到！ | 原来……火当不了太阳。 |
| 土伯 | 活人，回去。 | 君无下此幽都！ | 门……撑不住了！ | 门交给你了……让我闭一会儿眼。 |
| 刑天 | 帝！你又来了！ | 头可以不要，这一仗要打完！ | 猛志固常在！ | 不是帝啊……只是天黑了。 |
| 相柳 | 饿。 | 饿。饿。饿。 | 饿饿饿饿饿饿饿饿饿。 | ……还是饿。 |
| 长夜 | 嘘，它还在睡。 | 我从灯里，看了你们一千年。 | 它……要醒了。 | （没有台词。烛龙睁眼。） |

- 毕方的登场就是《西山经》的“其鸣自叫”；土伯的第二阶段是《招魂》原句；刑天的第三阶段是陶渊明的诗，和阶段名“猛志常在”对上；相柳的第三阶段是九个头一起喊。
- 土伯的第三阶段叫“门破”（原名“开鬼门”）：他一心关门，不会亲手开门，是撑不住了，门被冲开。
- 真结局里四个夜主来援，各有一句台词，见第 8 节。
- 小头目可以各有一句（建议）：判官“生死簿上，有你的名字。”；祸斗“嗝。”（刚吃完火）；鲲和骑俑不说话。

**无尽夜**【新】：夜主倒下不天明（第 8 节），所以“倒下”那句换成“退去”，之后每次回来说“再来”那句；登场、换阶段照常。长夜不进无尽夜。

| 夜主 | 退去 | 再来 | 呼应 |
| --- | --- | --- | --- |
| 九尾 | 光透不下来的……孩子们，再等等。 | 越往下，怕黑的孩子越多。 | 倒下时的“记得狐也怕黑” |
| 毕方 | 还没天亮？那我再烧！ | 毕方！毕方！毕方！ | 登场的“其鸣自叫”，一次比一次多喊一声 |
| 土伯 | 门还没关……我不能闭眼。 | 活人，你走得太深了。 | 倒下时的“让我闭一会儿眼” |
| 刑天 | 天没亮，仗就没打完。 | 再来！ | 第二阶段的“这一仗要打完” |
| 相柳 | ……饿。 | 更饿。 | 吃了还饿 |

夜主登场时名字下面那行题字：

| 时机 | 题字 |
| --- | --- |
| 夜行，夜主登场 | 击败它，迎来天明 |
| 无尽夜，夜主第一次登场 | 击败它，往深处走 |
| 无尽夜，夜主再来 | 它回来了，梦又深了一层 |

“深了一层”不写成“深了一更”：界面上的“更”是出发前选的难度，无尽夜里不会变。

## 8. 结局

**基调（2026-10-13 定）：苦尽甘来的史诗。** 核心不变：把借来的光还给烛龙、灯灭、念出名字。真结局的最后一夜做成群像大决战，前面埋下的线在这一夜一起收回。普通结局保持克制，和真结局形成反差。

- **普通结局**：击败长夜，梦破了，烛龙醒了一半。它只睁得开一只眼，天亮了，只是鱼肚白。烛龙看了你一眼，又看了看你的灯。夜还会来，但会过去。
- **真结局**：五缕烛火都在灯阵完整的夜里取得，再通关一次终章。长夜的三个阶段之后，多出最后一段。
  1. **梦碎**：击败长夜，梦破了，烛龙要醒了。真正的天亮一来，鬼门就会永远关上。
  2. **九首吞日**：门外的百鬼不甘心，由相柳的九个头领着涌上章尾山，要把烛龙刚睁开的眼吞掉。相柳吞过玄火，还想吞下整只眼。玩法上是守住山顶中央的“烛眼”（烛龙半睁的眼）；相柳的头打疼了会缩回去，打不死，要等天明才散（`GAMEPLAY.md` 9.5）。
  3. **四方来援**：四个被你击败、解开了心结的夜主赶来，以全屏援助出手。相柳是唯一纯粹的恶，它在对面。

     | 夜主 | 来做什么 | 台词 | 呼应以前的哪句 |
     | --- | --- | --- | --- |
     | 九尾 | 举起青火照亮东方 | 孩子们，睁眼。 | 第三阶段的“孩子们，闭上眼。” |
     | 毕方 | 冲上天，替真正的太阳开路 | 这回，我替太阳开路！ | “原来……火当不了太阳。” |
     | 土伯 | 守在鬼门边，等天一亮就关门 | 天一亮，门就关得上了。 | “让我闭一会儿眼。” |
     | 刑天 | 领着常羊的兵俑守住山道 | 这一仗，我替你打。 | “头可以不要，这一仗要打完！” |

  4. **万灯**：烛阴卫是烛龙梦里历代守灯人的影子。梦碎了，他们放下兵刃，一起举起灯：一千年的守灯人站成一座灯阵。玩法上要去点亮他们举起的 12 盏灯，正合十二时辰：十二盏亮了，一整天就回来了。
  5. **还光**：烛龙在灯阵的光里开口：“光，你们借了一千年。”你明白了：借期早就到了。你打开灯罩，长明火化成一道贯天的光柱，回到烛龙眼里。灯灭了。
  6. **天明横扫五方**：五缕烛火和借出去的那缕都回来了，烛龙睁开双眼。天光从东方青丘起，依次照过丹穴、幽都、常羊、北冥，每到一处，那里的颜色就回到画里：
     - 青丘：狐村的孩子不用再怕黑。
     - 丹穴：凤凰归来，百鸟朝凤，毕方飞在鸟群里。
     - 幽都：门神的画像重新上了色；土伯关上鬼门，终于闭上了眼。
     - 常羊：俑一排排躺回土里，刑天放下干戚。
     - 北冥：冰面裂开，海又动了，鲲化为鹏，往南冥飞去。
     - 章尾山：相柳和百鬼在日光里化成墨烟。
  7. 烛龙最后一句：“……够了。光我收回，灯留给你们。”
  8. **灯驿**：灯童掀开你的灯座，念出压在下面的名字，这时由玩家输入。百姓各自用自家的火点灯，一盏点着下一盏（一灯燃百千灯）。
  9. 最后一句：“灯可以灭，心灯不灭。”
- “灯灭”这个词只留给真结局。平时的失败叫“倒下”，结算页标题用“夜未尽”，和“天明”相对。
- **之后的模式**：
  - 无尽夜（通关青丘一更后开放，`GAMEPLAY.md` 3.4）：长夜这场梦有深有浅。平常的一夜，夜主一倒，光透出来，那一片梦浅了，就天明。无尽夜是守灯人不等天明，提着灯往梦的深处走：梦太深，光透不上来，夜主倒下也不天明；梦重做得越快，夜就一层层深下去，夜主一次次回来，一次比一次凶。为什么要往深处走：梦越深，困在里面的魂越多，能引一个是一个。真结局以后烛龙醒了，可它做过的梦沉到了夜底，还没散尽，守灯人照样能下去。
  - 无灯（真结局后解锁）：长明火还了，只剩心灯那一点光（照见圈 80）。收魂、照出法器，靠的都是它。
  - 真结局以后再择灯，灯里点的是灯驿百姓自家的火。
- **画面建议（给美术）**：长夜里的画只有墨色；每拿回一缕烛火，那个地区天明时多回来一种颜色；真结局五色全回来。和“墨色为主、淡彩为辅”的画风一致。真结局的“天明横扫五方”是全游戏最大的场面，可以做成一幅从东到北展开的水墨长卷。

## 9. 道具关联

### 9.1 四种关联

| 关联 | 意思 | 例子 |
| --- | --- | --- |
| 同源 | 道具来自某个妖物、夜主或地区 | 毕方羽来自毕方；冰魄珠来自北冥的冰魄；墨斗、镇妖塔来自土伯；孔明灯来自狐村 |
| 同链 | 一件法器和它的心法钥匙、进化、异化、合璧，共用一个意象 | 纸鹤 → 折纸 → 千鹤引 → 铁鹤 → 百鸟朝凤 |
| 同组 | 名字出自同一个故事或同一群人 | 哪吒：风火轮、乾坤圈、补给莲子、北冥的夜叉。更夫：风灯、更锣、夜签长更 |
| 同字 | 名字里同一个关键字，意思和效果相通 | 带“血”的都是拿凶险换收获：血月、血祭坛、血玉 |

**关键字表**：名字里出现这些字，就得是这个意思；反过来不要求。“灯”“星”“火”这类太常用的字不进表。

| 字 | 意思 | 例子 |
| --- | --- | --- |
| 烛 | 烛龙的光，或烧自己照别人的火 | 烛龙、烛火、烛眼、烛阴卫、烛泪 |
| 照 | 用光照到或看穿 | 照见、照见圈、照妖镜、照夜珠、照落、流派照夜 |
| 魂 | 魂火、引魂 | 魂火、引魂、聚魂、魂灯、引魂铃、迷途魂 |
| 影 | 黑暗做成的东西 | 影妖、疾影、影卫、各地妖物的影、夜主残影 |
| 幻 | 狐的幻术 | 幻身、狐火幻象 |
| 残 | 剩下的、破的 | 残灯、残影、天书残页 |
| 冢 | 埋东西的坟 | 狐冢、兵冢、首冢、万剑冢 |
| 血 | 拿凶险换收获 | 血月（妖物多，魂火也多）、血祭坛（拿生命换宝箱）、血玉（挨打反击，回复变弱） |
| 琉璃 | 亮而易碎：伤害高，生命低 | 琉璃灯、琉璃夜 |
| 风 | 快，闪避和移动 | 风灯、风火轮、疾风、御风 |
| 疾 | 快 | 疾影、疾行、疾风、精英词缀「疾」 |
| 镇 | 土系的压制 | 镇岳、镇妖塔、镇邪、镇星 |
| 霜、寒、冰、冻、凝 | 水系的减速和冰冻 | 霜铃、寒山钟、寒意、冰魄、冰蚕、冻土、凝霜 |
| 狐 | 青丘狐族。只有小妖叫“狐火”，其余都是带“狐火”的复合名 | 狐火、狐火环、狐火雨、狐火幻象、狐火夜、讨封狐、赤面狐、鬼狐、狐冢、狐嫁女 |
| 鬼 | 鬼类，或和死人的魂有关的东西。“百鬼”“群鬼”这类泛称指所有妖物，不算 | 青面鬼、水鬼、鬼卒、鬼狐、鬼门、鬼市 |

由此要跟着改的两处说法：金蝉蜕留下的“残影”改叫“空壳”（它不是黑暗做的，是玩家的替身）；鬼狐分出的“幻影”改叫“幻身”。

- **异化**的名字要同时看得出原来那一系和克它的那一系：冰火两重天（水、火）、赤霄（火、剑）、铁鹤（金、鹤）、冻土（水、土）、竹印（竹从地下冲出来顶起石印：木、土）。原名“破土”和五行反应“裂土”是同一对五行、同一个画面，所以改。
- **合璧**的名字要看得出两系：百鸟朝凤（木、火）、焚岳（火、土）、万剑冢（金、土）、霜天剑雨（水、金）、春风化雨（春属木、雨属水）。
- **奇招**的名字说清两件法器碰在一起发生了什么：

| 奇招 | 由 | 关联 |
| --- | --- | --- |
| 漩涡 | 镇妖塔 + 沧浪 | 塔吞浪，浪绕塔 |
| 蒸浪 | 沧浪 + 灯火 | 水克火，冒蒸汽 |
| 剪纸 | 铜钱剑 + 纸鹤 | 剑气剪纸，民间剪纸 |
| 藤甲兵 | 青藤 + 撒豆成兵 | 《三国演义》的藤甲兵。他们怕火，被诸葛亮烧了；孔明灯也是诸葛亮的名字，可以做成一句彩蛋台词 |
| 照落 | 照妖镜 + 孔明灯 | 镜光一照，灯就落：一个字来自镜，一个字来自灯 |
| 烟幕 | 油纸伞 + 爆竹 | 水打湿爆竹，炸出蒸汽 |
| 回响 | 石敢当 + 霜铃 | 铃声撞上石碑弹回来 |

- 油纸伞和镇妖塔都出自白蛇传：雷峰塔压住水漫金山的白蛇，正是土克水。可以做成一个隐藏的小彩蛋（建议，给玩法）。

### 9.3 心法

每门心法要么对着一件法器（进化钥匙），要么对着本系的一种本事。

| 五行 | 心法 | 关联 |
| --- | --- | --- |
| 金 | 剑意、锐目、破军、迅锋 | 剑意对符剑；锐目对照妖镜（目对镜）；破军对七星铜钱剑（北斗）；迅锋：飞行物快 |
| 木 | 折纸、生生、回春、疾行 | 折纸对纸鹤；生生（《易》“生生之谓易”）对豆兵；回春对青藤；疾行：五行里风属木 |
| 水 | 静心、流转、寒意、引魂 | 静心对霜铃（寺钟静心）；流转对油纸伞（伞转）；寒意对沧浪；引魂：中元河灯给水里的魂引路 |
| 火 | 长明、炉心、传薪、灯芯 | 长明对灯火；炉心对爆竹（丹炉出火药）；传薪对孔明灯（前辈传下来的灯）；灯芯：照见圈和燃灯 |
| 土 | 厚德、磐石、镇邪、载物 | 厚德对山印，和载物合成“厚德载物”；磐石对石敢当；镇邪对镇妖塔 |
| 无 | 轻功、聚魂 | 轻功：闪避；聚魂：魂火价值（和“引魂”分工：引是拉过来，聚是多收） |

心法“薪火”和流派“星火”只差一个字，读音也只差前后鼻音，在很多口音里一样，所以心法改叫“传薪”。

## 10. 命名规则

新增名字照这个来，写进本文后再用。

1. **一名一义**：一个名字只指一样东西；同一样东西在设定和玩法里用同一个名字。
2. **有出处或有道理**：先找《山海经》《楚辞》《庄子》《淮南子》、志怪、民俗，其次诗词、成语。都没有，就要在本文里写清楚它在这个世界里为什么叫这个名字。续写的部分要写明是续写。
3. **有关联**：至少连着一样已有的东西（9.1 节的四种关联）；名字里用到关键字，要合关键字表的意思。
4. **合句式**：

| 类别 | 句式 | 例子 |
| --- | --- | --- |
| 法器 | 两到三字，守灯人带在身上或唤得出来的东西 | 符剑、照妖镜、沧浪 |
| 进化 | 意境或典故，看得出从哪件法器来 | 寒山钟、万剑归宗 |
| 异化 | 看得出原来那一系和克它的那一系 | 铁鹤、冻土 |
| 合璧 | 四字为主，看得出两系 | 百鸟朝凤、霜天剑雨 |
| 奇招 | 两到三字，说清两件法器碰在一起发生了什么 | 漩涡、剪纸 |
| 心法 | 两字心诀，看得出对着哪件法器或哪种本事 | 锐目、炉心 |
| 灯坠 | 挂得住的小物件：镇物、信物、宝物的小样 | 桃木符、冰魄珠 |
| 灯 | 材质或样式加“灯” | 霜瓷灯、走马灯 |
| 妖物 | 志怪、民俗里的名字，合地区的方位和五行 | 冰蚕、祸斗 |
| 险地 | 两到三字的地名，是地区的“深处” | 狐冢、冰渊 |
| 精英词缀、共鸣印 | 一字 | 疾、坚、隐；锐、生 |
| 夜签 | 两到三字，今夜的兆头 | 血月、灯花 |
| 奇遇 | 路上遇到的人、物、事 | 货郎、烂柯棋局 |
| 反应 | 两字，说清两系相遇发生了什么 | 蒸腾、熔金 |
| 局外属性 | 直白的属性名，不和心法、心灯重名（`GAMEPLAY.md` 11.2） | 伤害、续命 |
| 成就 | 四字为主，成语、诗句、典故，连着条件或奖励；不用系统名词 | 秉烛夜游、五灯会元 |

5. **颜色就是五行**：木青、火赤、土黄、金白、水玄。妖物名字里的颜色字，尽量和它的五行一致（例外：赤面狐的“赤”是脸上的朱砂，戏台上的红脸本来就表示忠勇，它是替九尾守村的）。
6. **不用**：
   - 现代词（火山口、金币这一类）；
   - 外来神话的设定（人鱼唱歌、吸血鬼）；
   - 金乌、十日这类会和烛龙抢“白天”的神话；
   - 同一大类里只差一个字、或读音相同的名字（金蝉/金蟾、星火/薪火、石灯/石灯笼）。同链、同组、同字的系列名除外，它们本来就该像（镇岳、焚岳；万剑归宗、万剑冢）；不同大类里意思一看就不同的常用词可以并存（灯花是夜签，灯火是法器）。
7. **ID 和中文名一一对应**：ID（`shade`、`lamp`）只在数据里用；界面一律用中文名。

## 附录：百妖谱样稿（M2 的 8 种）

**影妖**（鬼）
长夜里死去的人，没人引魂，魂被黑暗一层层裹住，就成了影妖。它们不记得自己是谁，只认得光，循着灯走来。打散了，墨壳一炸，魂就出来了。
弱点：照见圈里的影妖受伤更重。

**疾影**（鬼）
裹得薄的影妖，多是新死的魂，还没被夜压沉，所以又轻又快，一碰就散。
弱点：血少。范围法器一扫一片。

**石妖**（精）
山石在长夜里吸了魂，就成了精。走得慢，皮硬，敲碎了，魂从石缝里飞出来。
弱点：慢。拉开距离慢慢磨。

**赤面狐**（妖）
青丘的狐，替九尾守狐村的夜。脸上那抹红是朱砂，狐村的孩子给它画的，像戏台上的红脸。
弱点：精英里它的血最少，集中火力很快就倒。

**青面鬼**（鬼）
“青面獠牙”说的就是它。鬼门里出来的恶鬼头子，三年里吞了不少魂，个头大，血厚。
弱点：被它堵住时，闪避从它身边穿过去。

**石将**（精）
陵墓神道两旁的石人，民间叫翁仲。替死去的主人站了几百年岗，长夜里还在站，见了活人就当成盗墓的。
弱点：最慢。绕着它打。

**九尾**（妖·夜主）
《山海经·南山经》：“青丘之山……有兽焉，其状如狐而九尾，其音如婴儿，能食人，食者不蛊。”古书里它吃人，也是涂山的祥瑞。长夜里，它是狐村所有小狐狸的母亲。
弱点：九条尾巴，一个影子。有影子的才是真身，幻身进了照见圈就散。

**金蟾**（灵物）
刘海戏的那只吐钱的金蟾。长夜里它改吞魂火和钱，见了守灯人就跑。
弱点：追上它。它不还手。
