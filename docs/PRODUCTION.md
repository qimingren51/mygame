# 持续制作记录

用户目标是持续主导制作、打磨到高规格古风肉鸽游戏。主分支仅 `develop`，不向 `master` 集成。当前制作可自行决策、出样、审图与实施，不等待用户逐项确认。

这份记录用于交接当前工作与真实证据，不新增 CI、发布审批或交付门禁。一个工作包通过检查只代表该包可集成，不能据此宣称整款游戏达到 AAA 水准。

## 已进入集成版的第二轮工作

- 当前升级池的 39 种卡面已有正式插画：六件法器、六种进化、五种异化、三种合璧、十七门心法、两种补给。生成方式与全部提示词见 `art/cards/`；游戏使用独立 `cards` 图集，不再依赖小图标放大。
- 卡片按钮使用与深墨底匹配的浅色字，禁用按钮不抢焦点；图像、数值和说明分层，页脚操作保留目标卡的弱焦点。
- 青丘地表按成片土色、林缘积叶和疏朗通行带组织。狐祠/牌坊确实盖住主角时平滑退让，门洞和主角前方的建筑保持正常。
- 讨封狐播放完整现形动作；赤面狐在实际扑击结束后才落地；分裂小妖死亡时保持原体型。
- 主角改进面部侧形、发束、肩袖、交领与衣料分区。208 个姿态和三套灯笼叠层完整重渲，头像更新；挂点、动画定义、画布和锚点保留。主角细线只作用底图，灯笼使用原线宽。

实际证据：工作区格式、Clippy 和 432 项 Rust 测试通过；图集检查通过。主角四套素材各 208 个姿态通过既有素材检查，红灯色差实际修正，未放宽检查标准。保留的姿态高度与部分灯芯遮挡提示已结合八方向/逐帧图审查。实机已查看正式插画卡片、新主角移动和狐祠遮挡退让，画面见 [PLAYTEST.md](PLAYTEST.md)。

## 当前继续推进的工作

初期构筑节奏已通过审查并集成：把新牌权重改为类别预算，前五次给已有武器升级机会，提前提供进化钥匙选择，并只登记最终展示的新法器。旧的“前五次累计见两种新武器”规则并不保证第一屏有两件武器，不能把截图误判为该规则失效。独立审查发现的自然钥匙被补牌覆盖问题已复现并修正。

固定种子 42–44 的新档新手策略对照已完成：首次进化从 211.1、315.6、327.5 秒变为 190.6、355.4、308.7 秒。机会更明确不代表每局更快，不据三局推导整体平衡；具体口径见 [BALANCE.md](BALANCE.md) 8.1。格式、Clippy 和 441 项工作区测试通过，2 项保持既有 ignored；实机查看随质变成果页更新继续。

质变成果画面正在改用实际进化、异化或合璧的插画，避免显示基础法器图标；赤面狐的造型与材质在独立工作树先做少量原生尺寸样张，未替换正式图集。

## 尚未达到制作目标的部分

游戏仍以青丘为主要可玩内容。完整世界、地区首领、法器与成长规模继续以 `GAMEPLAY.md` 和 `BALANCE.md` 为方向，不把这一局的精修当作整个目标完成。当前环境大体块、主要敌人造型、首领演出、其他奖励界面、听感与整局节奏仍有提升空间。主角第二版比旧版清晰，但仍是持续制作中的一版，不是最终角色美术。

后续优先让实际战斗和成长体验达到与卡面相称的质量，持续用真实游玩、回放、必要的代码/素材检查验证效果；不以单张精美插画或单次全绿测试替代游戏整体判断。
