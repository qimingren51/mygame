# 提灯夜行 · 设计文档

横屏、单手操作的肉鸽割草游戏。玩家是提灯的夜行人，在黑夜里斩妖，撑过 10 分钟妖潮并击败夜主即为“天明”。

- 在线游玩：<https://qimingren51.github.io/mygame/lantern/>
- 完整设计稿（界面与系统图，仅本人可见）：<https://claude.ai/artifact/9A3mhtorndrW3bqoSpAtve>

## 画风

墨蓝夜色 + 暖金灯光。灯笼照亮的范围之外一片漆黑，只能看见妖物发光的眼睛。标题用毛笔字（Ma Shan Zheng），数字和名称用宋体（Noto Serif SC）。

## 成长系统

核心目标：**每 10 秒一次获得，每 30 秒一次选择，每 3 分钟一次质变；每一局都离下一次解锁更近一步。**

### 三层循环

| 层级 | 内容 | 爽点 |
| --- | --- | --- |
| 秒级 · 割草 | 走位 → 自动攻击 → 妖物爆散 → 魂火飞来（落地 8 秒未拾取会自动归灯） | 暴击大字、连斩计数、引魂铃吸魂 |
| 分钟级 · 构筑 | 升级三选一（重抽 / 跳过）、精英宝箱 1/3/5 连开、五行共鸣、进化 | 共鸣跨阶、宝箱揭晓、进化演出 |
| 局级 · 养成 | 灯油 → 心灯永久加成；解锁新内容；夜深难度 | 解锁、新流派首次成型 |

### 五行共鸣

每件法器、每门心法都带一个五行属性；满级的法器和心法计 2 点。同系达到 2 / 4 / 6 点触发共鸣：

| 共鸣 | 2 点 | 4 点 | 6 点 |
| --- | --- | --- | --- |
| 金 · 锐 | 暴击率 +10% | 暴击伤害 +50% | 暴击时追加飞剑 |
| 木 · 生 | 每秒回复 0.5% 生命 | 数量 +1 | 击杀回复生命 |
| 水 · 凝 | 命中减速 | 命中有概率冰冻 | 冰冻目标易伤并碎裂 |
| 火 · 焚 | 命中附加灼烧 | 灼烧可叠加 | 妖物死亡时爆炸 |
| 土 · 固 | 周期获得护盾 | 击退加倍 | 护盾破碎时震地 |

相邻两系同时激活触发相生：木生火（灼烧 +30%）、火生土（护盾恢复加快）、土生金（击晕目标必定暴击）、金生水（暴击减速）、水生木（回复翻倍）。五系全部激活触发「太极」：每 30 秒全屏轮转一次五行伤害。

### 进化

法器满级（Lv8）并持有对应心法后，下次升级必出进化选项：

| 法器 | 心法 | 进化 |
| --- | --- | --- |
| 符剑（金） | 剑意 | 万剑归宗 |
| 纸鹤（木） | 折纸 | 千鹤引 |
| 霜铃（水） | 静心 | 寒山钟 |
| 灯火（火） | 长明 | 不夜城 |
| 山印（土） | 厚德 | 镇岳 |

### 单局节奏（10 分钟）

| 时间 | 阶段 | 事件 |
| --- | --- | --- |
| 0–3 分 | 生存期 | 快速升级，铺开火力 |
| 3:00 | — | 精英「赤面狐」，掉落宝箱 |
| 3–6.5 分 | 构筑期 | 凑共鸣、定流派 |
| 5:00 | — | 小头目「青面鬼」 |
| 6.5–10 分 | 割草期 | 进化爆发 |
| 8:00 | — | 妖潮来袭（30 秒刷怪 ×2.5） |
| 9:30 | 决战 | 夜主「九尾」降临，击败即天明 |

关键数值：升级所需魂火 `4 + 5n + 0.6n²`；魂火掉落倍率 `1 + 0.25 × 分钟`；妖物血量倍率 `1 + 0.3m + 0.07m²`；每秒刷怪 `1.6 + 1.1m + 0.1m²`（m 为分钟）。

### 随机性：每局都不一样

| 系统 | 内容 |
| --- | --- |
| 夜签 | 开局从 10 种规则里随机抽 3 张，选 1 张。每张都有好处和代价，例如血月（魂火 +35%，妖物 +35%）、琉璃灯（伤害 +40%，生命 -35%）、五行偏重（随机一系开局即得 2 点共鸣）。 |
| 奇遇 | 每 40–65 秒随机出现一个，屏幕边缘有箭头指引。金蟾：会逃跑，打死散财。灵泉：站在里面回血。古灯：30 秒随机增益。血祭坛：以 25% 生命换一次强化。妖潮裂隙：一群妖加一个守卫，打死守卫得宝箱。 |
| 精英 | 出场时间在区间内随机，种类从赤面狐、青面鬼、石将中随机；妖潮的时间也随机。 |
| 妖群 | 疾影、石妖的比例每局随机；成群妖物的方向和间隔随机。 |
| 地图 | 地面布局每局用不同的随机种子生成。 |
| 升级 | 10% 概率“灵光一闪”变成四选一。 |
| 音乐 | 旋律按本局种子随机生成。 |

### 画面视角

斜俯视（3/4 视角）：
- **主角**：Q 版比例，戴斗笠、穿交领长袍，系红腰带、红绸围巾，手提红纸灯笼；走路会迈步，左右转身。造型代码单独放在 `sprites.js`。
- **妖物**：悬浮在地面之上，带影子。
- **遮挡**：所有角色按纵坐标从远到近绘制，近处的挡住远处的。

### 全屏

- **安卓 / 电脑**：用浏览器的全屏接口，出发时自动全屏并锁定横屏，标题页和暂停页也有「全屏」按钮。
- **iPhone**：Safari 不支持网页全屏，改用 `manifest.webmanifest` 和 Apple 专用的页面设置。“添加到主屏幕”后，从桌面图标打开就是全屏横屏。标题页会提示操作方法。
- **微信 / QQ 内置浏览器**：提示用户改到系统浏览器打开。

### 音效与音乐

全部用 Web Audio 实时合成（`audio.js`），不需要音频文件。

- **乐器**：古筝式拨弦、编钟、太鼓、木鱼、锣，音阶为 D 羽调五声音阶。
- **背景音乐**：低音持续音、随机生成并逐渐变奏的旋律，鼓点随局势加强：
  - 生存期只有拨弦。
  - 构筑期加入木鱼。
  - 割草期加入太鼓。
  - 夜主出现后换成更快、更紧张的鼓点。
- **界面**：升级、暂停时音乐变闷。
- **音效**：命中、击杀、拾取魂火（连续拾取音高一路爬升）、升级、宝箱、共鸣、进化、燃灯、闪避、受伤、精英与夜主预警、胜利与失败等。
- **开关**：标题页和暂停页可分别开关音乐与音效，设置存在 `lantern_audio`。
- **iPhone 兼容**：每次点击都尝试恢复音频；在用户手势里先播放一段空白声音来解锁；把音频会话切到“播放”类型，并循环播放一段静音音频，这样侧边静音键打开时也能出声。

### 局外成长

- **心灯**：锋芒（伤害）、体魄（生命）、灵巧（移速、拾取）、气运（重抽、宝箱），每系 5 级。总加成刻意控制在小幅，成长主要来自构筑。
- **灯油**：按存活秒数、击杀数、是否击败夜主结算；倒下也有收获。
- **结算钩子**：显示离下一盏心灯还差多少灯油。
