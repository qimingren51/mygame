# 提灯夜行（重构版）· 设计与技术文档

玩法设计沿用旧版，见 `../lantern/DESIGN.md`；里程碑 2 迁移玩法时会把那份内容并入这里。
本文件记录新版的技术架构、水墨画风、美术管线、调试方法和进度。

## 目标

- 更好的角色造型、交互和视觉效果：8 方向的 Blender 渲染角色、“灯照见画”的光照、上千只妖物同屏。
- 玩法逻辑与画面彻底分开：模拟可以无界面运行、按种子复现，方便做平衡测试。
- 性能以 iPhone（Safari / Chrome）为准：1000 只妖物 + 约 200 个光源时持续 50 fps 以上。

## 画风：水墨国风，“灯照见画”

- 世界是一幅宣纸上的水墨画，被黑夜笼罩。灯笼、火焰、魂火照到的地方显出画面，暗处只剩妖物发光的眼睛。
- 主角是“提灯剑修”：约 5 头身的少年修士。高束发髻配玉冠，朱砂发带向后飘，交领宽袖长袍用花青淡彩，背负长剑，右手提一盏红纸灯笼当作法器。
- 颜色以墨色为主，淡彩为辅，只有灯笼、发带、穗子这类小面积的地方用纯朱砂、藤黄。
- 唯一的风格来源是 `art/style/style.py`：调色板、尺寸、相机、线宽、输出约定都在这里。

## 架构要点

**主循环**：模拟固定 1/60 秒一步，一帧最多补 4 步；画面按插值系数画在两步之间。30Hz、60Hz、120Hz 屏幕上的玩法完全一致。

**随机数**：每局一个种子，按用途分成独立的流（夜签、开局、刷怪、战斗、掉落、奇遇、选项、宝箱）。纯装饰的随机（粒子、震屏）在画面层用 `Math.random`。

**模拟与画面的连接**：
- 低频事件走 `EventBus`（受伤、闪避、震屏、闪光、升级）。
- 高频事件走 `FxQueue`（命中、击杀、拾取），预分配的 Float32Array，不产生垃圾。
- 画面层每帧取走两者，同时转给音频层。
- 输入是每步一个 `InputFrame` 加命令队列（闪避等）。

**实体存储**：妖物按字段分数组（SoA），容量 2048，用“槽位 + 代号”句柄代替对象引用。空间网格以玩家为中心，每步用计数排序重建。

**渲染图层**（从下到上）：宣纸 → 地面装饰 → 影子 → 墨迹 → 角色（按脚底 y 排序）→ 暗层 → 火焰 → 自发光（叠加）→ 伤害数字 → 屏幕闪光。

**光照图**：
- 每帧把所有光源（径向渐变贴图，叠加混合）画进一张低分辨率的 RenderTexture，底色是夜色 `#161B2C`。
- 再以正片叠底盖在地面和角色上。
- 自发光层在暗层之上，所以妖眼在暗处也亮。
- 注意 Pixi 8 的两个坑：
  - ParticleContainer 不会叠加渲染根节点自己的变换，镜头变换要放在下一层。
  - RenderTexture 改尺寸后，引用它的 Sprite 不会更新，要换一张新的。

**角色层**：先把本帧要画的东西按 y 排好，再按顺序填进固定的对象池，不对子节点排序。两种实现在同一接口后面：B（Sprite 池，默认）和 A（ParticleContainer）。调试面板可以实时切换。

**画质自适应**：帧时间偏高时，按“分辨率 → 光照图 → 辉光”的顺序逐级降低，回落后再恢复。屏幕刷新率取最近几秒最短的帧间隔，所以低电量模式下的 30Hz 不会被误判为卡顿。

## 美术管线

1. `art/style/style.py`：风格常量（只改这一个文件）。`art/style/bstyle.py`：Blender 辅助函数，包括相机、假卡通材质、Freestyle 墨线、一次渲染导出填色 / 墨线 / 自发光三层、挂点投影。
2. `art/models/*.py`：程序化建模（主角、影妖、石块……），带 8 方向和动画姿势。
3. `art/render/*.py`：渲染。最终渲染用文件锁排队。
4. `art/post/postprocess.py`：后期。缩小 4 倍、墨线晕染、吸附调色板、叠纸纹、往透明区扩色、生成白色剪影帧。
5. `art/post/check_asset.py`：自检。不贴边、脚底漂移、身高、调色板、墨线占比、挂点。
6. `art/post/vfx_textures.py`：特效和地面贴图（只用 Pillow / numpy）。
7. `art/post/pack_atlas.py`：打包成 Pixi 图集，写到 `public/assets/`，并维护 `index.json`。游戏只加载清单里有的图集，缺的部分用代码生成的占位图。

## 调试

**地址参数**：

| 参数 | 作用 |
| --- | --- |
| `enemies=1000` | 场上保持的妖物数量（0–2000），同时显示性能面板 |
| `seed=123` | 固定种子 |
| `actors=A` | 角色层用 ParticleContainer 实现（默认 B） |
| `bloom=off\|baked\|filter` | 辉光模式，锁定后不自动降级 |
| `res=1.5` | 锁定画面分辨率 |
| `ls=0.25` | 锁定光照图比例 |
| `lights=300` | 光源上限 |
| `auto=1` | 开始测试后主角自动绕圈 |
| `debug=1` | 显示性能面板 |
| `benchStage=10000` | 跑分每段的毫秒数（测试用） |

**调试面板**：游戏中点右上角“调”，可以实时开关光照、伤害数字、辉光、分辨率、光照图、角色实现、妖物数量、自动画质、性能面板。

**跑分**：标题点“跑分”。250、500、1000、1500 只妖物各跑 10 秒，跑分期间画质固定。结束后出结果卡片，可以一键复制。

**`window.__lantern`**：world、presenter、quality、input、loop、artReport，给 Playwright 和手动调试用。
